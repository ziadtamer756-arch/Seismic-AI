# Research Contributions

The project contributions include:

## 1. Integrated Seismic AI Framework

A complete pipeline combining:

- Earthquake data processing
- Machine learning prediction
- Explainable AI
- Interactive visualization


## 2. Multi-model Evaluation

The framework compares several machine learning approaches instead of relying on a single model.


## 3. Robust Evaluation Pipeline

The project includes:

- Cross-validation
- Baseline comparison
- Hyperparameter tuning
- Ablation analysis
- Confidence interval estimation


## 4. Explainable Predictions

SHAP-based analysis provides insight into feature influence on model decisions.


## 5. Interactive Research Dashboard

A Streamlit dashboard provides:

- Earthquake statistics
- Model performance
- Prediction explanation
- Geographic visualization
- Evaluation reports
