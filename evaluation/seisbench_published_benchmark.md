\# SeisBench Baseline - Published Benchmark



\## Dataset

STEAD (Stanford Earthquake Dataset)



\## Toolbox

SeisBench



\## Task

\- Earthquake Detection

\- P-wave arrival picking

\- S-wave arrival picking





\## Pretrained Models



| Model | Task |

|------|------|

| PhaseNet | P/S Phase Picking |

| EQTransformer | Detection + P/S Picking |

| GPD | Phase Picking |





\## Evaluation Metrics



\- Detection performance

\- P arrival time residual error

\- S arrival time residual error





\## Source



Results are based on published benchmark evaluations of pretrained seismic models using SeisBench and STEAD.
